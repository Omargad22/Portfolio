# Professional CV in LaTeX

This directory contains a professional CV generated from your portfolio content.

## File
- `CV.tex`: The LaTeX source code for your CV.

## How to Compile
To generate the PDF version of your CV, you can use any LaTeX distribution (like TeX Live, MiKTeX, or MacTeX) and run the following command in your terminal:

```bash
pdflatex CV.tex
```

Alternatively, you can upload the `CV.tex` file to an online LaTeX editor like [Overleaf](https://www.overleaf.com/).

## Features
- **Clean Layout**: Uses the `article` class with optimized margins.
- **Modern Icons**: Includes `fontawesome5` icons for contact info.
- **Hyperlinks**: Clickable links for email, GitHub, LinkedIn, and projects.
- **Structured Sections**: Organized into Summary, Education, Experience, Achievements, Projects, and Skills.
